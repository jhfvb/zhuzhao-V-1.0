## 如何通过多线程来执行算法

为什么要在子线程中执行算法？

我们点击一个按钮，单次运行，那我们可以直接去执行这个算法。但如果这个算法的运行时间是5s，会造成什么呢？我们的主界面在这5s的时间内没办法点击，会卡死直到算法执行完毕。

所以我们要将算法的执行放到子线程中。或者说，任何耗时的操作，都应该放到子线程中，算法执行只是其中的一种情况。

### 1、重写QThread类，填充实现算法执行过程

```c++
class ZZProcessThread : public QThread
{
public:
    ZZProcessThread();
    void SetPhotometricStereoParams(QList<QImage>& srcImages,
                                    QList<float>& Slants,
                                    QList<float>& Tilts);

    void GetResultImages(QList<QImage>& dstImages);

protected:
    void run() override;
private:
    volatile bool m_bIsStop;
    QList<QImage> m_srcImages;
    QList<QImage> m_dstImages;
    QList<float> m_Slants;
    QList<float> m_Tilts;
};
```

主要是重写run函数，run函数内的执行动作都会在子线程中运行。

同时还要开两个接口，分别是传入参数和获取结果。

### 2、调用子线程类对象

我们声明一个子线程类对象指针，当点击单次运行时，则执行如下过程：

```c++
    if ((message & MESSAGE::ZHUZHAO_RUNONCE) == MESSAGE::ZHUZHAO_RUNONCE)
    {
        //单次运行一次
        QList<QImage> srcImages;
        QList<float> Slants;
        QList<float> Tilts;
        m_pConfigWidget->GetPhotometricStereoParams(srcImages,Slants,Tilts);
        m_pRunProcess->SetPhotometricStereoParams(srcImages,Slants,Tilts);
        m_pRunProcess->start();
    }
```

分三步：

1. 从配置界面获取配置的参数
2. 将参数设置给算法子线程类
3. start运行子线程类

### 3、子线程运行完毕进行结果显示

子线程运行完毕，我们会拿到算法运行的结果图像，我们需要将结果图像进行显示。所以如何得知子线程运行完毕了呢？可以通过QThread类的finished信号得知。

创建信号槽：

```c++
m_pRunProcess = new ZZProcessThread();
connect(m_pRunProcess,&ZZProcessThread::finished,this,&MainWindow::OnProcessThreadFinished);
```

槽函数内部，从子线程获取结果，并将图像设置到缩略图列表进行显示：

```c++
void MainWindow::OnProcessThreadFinished()
{
    //算法执行完毕，刷新结果数据
    QList<QImage> dstImages;
    m_pRunProcess->GetResultImages(dstImages);
    m_pHThumList->clearAllImages();
    m_pHThumList->addImages(dstImages);
}
```
